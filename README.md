# Dijital Çakı

Fotoğraf, video, belge, kitap ve QR araçlarını bir araya getiren, tarayıcıda çalışan araç merkezi.

[Dijital Çakı’yı aç](https://dogukaska.github.io/)

Dijital Çakı’nın ana sayfası ve araç kataloğu Claude ve OpenAI Codex’in katkılarıyla geliştirildi, ortak tarayıcı testleri OpenAI Codex desteğiyle eklendi.

Kataloğun iki sütunlu görünümü ve açılır araç listeleri OpenAI Codex desteğiyle geliştirildi ve test edildi.

Ev araçlarının kataloğa eklenmesi, Tarif Kartı bağlantısının taşınması ve tarayıcı testleri OpenAI Codex desteğiyle yapıldı.

Döviz ve Altın Çevirici’nin erken fiyat isteği, yükleme durumu ve tarayıcı testleri OpenAI Codex desteğiyle geliştirildi.

Dosya Paylaşımı aracının katalog ve tarayıcı testleri OpenAI Codex desteğiyle güncellendi.

[Hesaplama kategorisinin](https://dogukaska.github.io/hesapkitap/) [kaynak kodu ve hesaplama testleri](https://github.com/dogukaska/hesapkitap) OpenAI Codex desteğiyle kendi deposuna taşındı.

Katalogdaki araçların ekran genişliklerine göre form yerleşimi kontrolleri OpenAI Codex desteğiyle eklendi.
